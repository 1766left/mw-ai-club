## 它适合做什么

- 从一句话描述直接生成一个能跑的网页 / 小应用
- 修改已有代码（"把这里改成……"）
- 生成图片、简单的视频
- 整理资料、写文档

## 它不适合做什么

- 替你想清楚要做什么（这是你自己的事，见[发现一个真问题](/kb/method/find-a-problem/)）
- 替你判断"这样做对不对"——涉及真实的人、真实的规则，得自己核

## 基本用法

1. 新建一个项目，取一个能被别人看懂的名字
2. 第一句话把**做什么 / 给谁用 / 关键动作 / 不能出现什么**写清楚（模板见[怎么跟 AI 提要求](/kb/method/prompting/)）
3. 每次只改一件事，改完立刻看效果
4. 满意了再继续，不满意就撤销回上一步

## Club 里的约定

- 所有项目的说明文档写在项目文件夹的 `README.md`，不要散在聊天里
- 交给别人试之前，自己先把所有按钮点一遍
- 生成的图片如果是占位图，在文件名里写明 `placeholder`
