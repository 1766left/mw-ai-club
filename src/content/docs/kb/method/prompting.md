## 模板

不要写「做一个图书管理页面」。按这个结构写：

```text
【做什么】做一个给社区家长用的借书页面。
【给谁用】40 岁左右，不太熟悉手机应用，不会看英文。
【关键动作】找到一本书 → 确认可以借 → 约一个交接时间。
【不能出现】注册流程、超过 3 项的填表、任何促销式文案。
【现在的样子】空白页 / 截图 / 上一版代码。
```

后面三行比第一行重要得多。**AI 不知道你的用户是谁，你得告诉它。**

## 三个最常犯的错

### 错 1：一次让它改五件事

同时改"配色 + 布局 + 加功能 + 修 bug"，出问题的时候你不知道是哪一处引起的。

一次只改一件事，改完立刻看。慢，但不用回滚。

### 错 2：只描述"要什么"，不描述"不要什么"

"不要出现弹窗""不要用英文""不要动这一块"——限制条件往往决定结果能不能用。

### 错 3：看不懂的代码留着

至少要做到能说出：**这段在干什么、为什么放在这里。**

说不出来的部分，就是以后一定会炸的地方。

## 卡住的时候怎么问

带上三样东西：

| 要带的 | 例子 |
| --- | --- |
| 你做了什么 | "点了提交按钮" |
| 发生了什么 | "控制台报 `Cannot read properties of undefined`，页面没变化" |
| 你期望什么 | "应该保存并跳到列表页" |

只写"不work"、"报错了"，AI 只能猜。它猜错的概率不低。
